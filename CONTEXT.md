# ZENJI Storefront

A responsive one-page e-commerce storefront for limited-edition anime streetwear drops.

## Language

**Drop**:
A finite, scheduled release of limited-edition apparel pieces that is printed once and never restocked.
_Avoid_: Collection, restock, batch

**Piece**:
An individual apparel design (such as an oversized graphic tee) cut from 240gsm heavyweight cotton.
_Avoid_: Shirt, item, merchandise, product SKU

**Line Item**:
A specific combination of a piece, chosen size variant and quantity currently present in the cart.
_Avoid_: Cart row, order entry

**Cart**:
The client-side sliding drawer that manages line items, quantity adjustments and live subtotal calculations.
_Avoid_: Bag, basket

**Size Variant**:
The standardized garment cut (XS, S, M, L, XL, XXL) selected before a piece can be added to the cart.
_Avoid_: Fit, dimension, option
