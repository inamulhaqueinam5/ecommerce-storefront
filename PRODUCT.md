# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack
Vite + React + TypeScript + Tailwind CSS

## Users
Australian anime and streetwear fans (gamers, otaku and shonen fans) looking for graphic tees that treat anime references as design-first, wearable anywhere without explanation. Also, the hiring assessment evaluators reviewing brand fit, visual quality, mobile usability, functionality and code clarity.

## Product Purpose
Deliver a responsive, high-converting one-page streetwear storefront for ZENJI's limited-edition anime apparel drops, demonstrating peak frontend craftsmanship, authentic brand alignment, tactile animations and an intuitive demo cart experience.

## Positioning
Limited-run Australian anime streetwear with Japanese-inspired minimalist restraint: 240gsm heavyweight cotton, original hand-drawn drop artwork, oversized streetwear cuts and zero restocks ("No restocks. Ever.").

## Operating Context
Single-page e-commerce storefront accessed on mobile and desktop browsers. Features a branded header, hero announcement with clear CTA, 6-item curated drop catalog with size selectors, interactive slide-over cart drawer and keyboard-accessible controls.

## Capabilities and Constraints
- Capabilities:
  - Responsive hero section with dynamic CTA ("Shop the Drop").
  - 6-item authentic drop catalog with interactive image presentation, badge labels and size pickers (XS to XXL).
  - Slide-over cart drawer with animated open/close, item quantity adjusters, item removal and real-time subtotal calculation.
  - Rich micro-interactions and animations powered by Framer Motion and Lucide icons.
  - Toast notifications when items are added to cart.
  - Interactive mock checkout with order summary confirmation modal.
- Constraints:
  - Client-side only; zero real payment gateway, account login or persistent database required.
  - Pure frontend bundle with lightning-fast load times and accessible keyboard navigation.

## Brand Commitments
- Name: ZENJI
- Voice: Minimalist, confident, shonen-arc lore, Japanese streetwear restraint.
- Core motifs: Heavy cotton (240gsm), katakana subtitles (ゼンジ), drop badges (`[DROP_01]`, `LATEST_DROPS`), muted dark palette (`#09090b`, `#18181b`) with crimson accents (`#e11d48`).
- Tagline: "Wear the Arc. Anime-inspired streetwear for gamers and otaku. Every drop limited. No restocks. Ever."

## Product Principles
1. Design-First Streetwear: Anime references must read as elevated fashion and graphic design, avoiding tacky or cheap novelty aesthetics.
2. Tactile Impeccable Motion: Micro-interactions (hover states, drawer slide, badge pulses and cart count increments) should feel fluid, purposeful and high-end.
3. Zero-Friction Cart: Selecting a size, adding to cart, adjusting quantities and viewing subtotals must be instant with zero page reloads.
4. Total Responsive Polish: Seamless experience on mobile devices and wide desktop displays with rigorous keyboard accessibility.

## Accessibility & Inclusion
Keyboard navigable controls, semantic HTML landmarks (`header`, `main`, `section`, `dialog`), ARIA labels on icon buttons and cart controls, WCAG AA contrast compliance against dark surfaces.
